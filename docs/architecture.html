Factory Inventory Management

A demo dashboard: a Vue 3 single-page app talks to a FastAPI backend over JSON. There is no database. The backend loads JSON files into memory when it starts and filters them for each request.

Data flow: a filter change

  1. User picks a filter in FilterBare.g. Warehouse = "Tokyo". It writes to a module-level ref in useFilters.js. Every view shares the same state because the refs are created once, outside the function.
  2. The view's watch() firesDashboard and Orders watch all 4 filters. Inventory, Demand and Backlog watch only warehouse and category. Spending watches only the period.
  3. getCurrentFilters() → api.jsBuilds query params and leaves out any value equal to "all", e.g. GET /api/orders?warehouse=Tokyo&month=Q3-2025.
  4. FastAPI filters in memoryapply_filters() does exact matching (case-insensitive for category and status). filter_by_month() matches substrings of order_date, with quarters expanded through QUARTER_MAP.
  5. Pydantic validates and serializesEndpoints that have a response_model drop unknown fields and reject bad shapes. Spending and report endpoints return raw dicts.
  6. The view stores raw data in refs, derives the restKPIs, chart series and table rows are computed properties, so the UI updates automatically. Currency and labels go through useI18n.

Things worth knowing

Gap Client calls missing endpoints

  • api.js defines /api/tasks (GET, POST, PATCH, DELETE) and /api/purchase-orders, but main.py doesn't implement them. Calling them returns 404 or 405.
  • Backlog.vue exists but has no route in main.js.

Quirk Inconsistencies

  • total_backlog_items in the dashboard summary ignores every filter.
  • The quarterly report repeats the quarter logic with if/elif instead of reusing QUARTER_MAP. Both only cover 2025.
  • Reports.vue hardcodes the API URL instead of using api.js.

By design Demo constraints

  • Data is read-only and resets on restart. There is no persistence layer.
  • CORS allows any origin. That's fine locally but not for deployment.
  • Authentication is a mock user in useAuth.js.
